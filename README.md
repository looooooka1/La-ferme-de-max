# La Ferme de Max

Site statique (sans build) : `index.html` (accueil immersif) et `reservation.html` (disponibilités et demande de séjour).

## À renseigner avant mise en ligne
- `reservation.html` : objet `CONFIG` en haut du script (`endpoint` ou `email`) pour que les demandes partent automatiquement.
- `data/dispos.json` : plages bloquées par gîte, puis `"confirmed": true` quand elles reflètent le calendrier réel.
- Remplacer `https://looooooka1.github.io/ferme-de-max/` par le domaine définitif (canonical, Open Graph, sitemap, robots, données structurées).
- Logo : la marque actuelle est une proposition, à remplacer par le logo officiel du client.
